2Naturaleza de los servicios

Se ofrecen servicios técnicos independientes de automatización, análisis de datos, análisis de bases de datos, depuración de código y consultoría técnica, conforme se describen en la sección Services. Los servicios se prestan de forma remota y personalizada según el alcance acordado con cada cliente.

3Proceso de contratación y pago

Este sitio no procesa pagos de forma automática. El cliente contacta al prestador por correo electrónico (corekeepper@gmail.com) para definir el alcance del servicio. Una vez acordado, el prestador envía directamente al cliente un enlace de pago. El servicio se agenda o inicia una vez confirmado el pago, salvo acuerdo distinto entre las partes.

4Cancelaciones y reembolsos

Si el trabajo aún no ha comenzado, el cliente puede solicitar cancelación y reembolso completo. Una vez iniciado el trabajo, los reembolsos se evalúan caso por caso según el avance realizado, a criterio razonable del prestador.

5Propiedad y entregables

Salvo acuerdo distinto por escrito, los entregables (código, análisis, reportes o automatizaciones) desarrollados específicamente para el cliente pasan a ser de uso del cliente una vez liquidado el pago correspondiente. El prestador conserva el derecho a reutilizar conocimiento y técnicas generales no específicas del cliente.

6Limitación de responsabilidad

El prestador actúa con diligencia profesional, pero no garantiza resultados específicos de negocio derivados del uso de los entregables. El prestador no es responsable por daños indirectos derivados del uso de automatizaciones, análisis o código entregado, más allá del monto pagado por el servicio correspondiente.

7Modificaciones

Estos términos pueden actualizarse periódicamente. La versión vigente es siempre la publicada en esta página.
